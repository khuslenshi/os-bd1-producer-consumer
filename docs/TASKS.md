# 7-р долоо хоногийн ажил (Core + UI + холболт → MVP)

Одоо repo-д **ажиллаж буй эхлэл** байгаа (core, server, UI, тест). 7-р 7 хоногт багаараа үүнийг **ойлгох, өөрийн болгох, сайжруулах, шалгах**.
Шаардлага: гишүүн бүр **өөрийн branch-ээс commit/PR** хийнэ (GitHub ажиллагаа тайланд орно).

## Эхний 30 минут (бүгд)
1. Repo-д энэ хавтсыг оруулах (1 хүн `main` рүү push, бусад `git pull`).
2. Бүгд Quick Start-аар ажиллуулж үзэх (README). Алдаа гарвал issue нээх.
3. Доорх issue-г GitHub дээр үүсгэж хүн бүрт оноох.

## 7 хоногийн хуваарь
- **1–2-р өдөр:** бүгд код ажиллуулж ойлгох, issue/branch, эхний PR-ууд.
- **3–4-р өдөр:** сайжруулалт, баг дотроо PR review (өөр хүн merge хийнэ).
- **5-р өдөр:** бүгд хамт **цэвэр машин дээр** README-ээр clone→build→run шалгах. Алдааг issue болгох.
- **7 хоногийн төгсгөл:** MVP `main` дээр, тест давсан. Tag-г 9-р 7 хоногт (`v1.0`).
