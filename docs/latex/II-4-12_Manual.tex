\section{Хэрэглэгчийн заавар}

\subsection{Программын зорилго}
Сурах бичгийн 7-р бүлгийн Producer-Consumer (bounded buffer) төслийг C хэл дээр pthreads, POSIX semaphore (\code{empty}, \code{full}), \code{mutex}-ээр хэрэгжүүлсэн. Producer thread-үүд санамсаргүй тоо (0-99) тойрог буферт тавьж, consumer thread-үүд авна. Browser дээрх дэлгэц нь \textbf{бодит C программын} thread бүрийн үйлдлийг (унтах, semaphore хүлээх, тавих, авах) буферийн анимаци болон thread бүрийн timeline хэлбэрээр харуулна. Дэлгэц зөвхөн харуулдаг, бүх синхрончлол C core дотор явагдана.

\subsection{Дэмжих орчин}
\begin{itemize}
  \item macOS (Apple Silicon / Intel), Linux (Ubuntu 22.04+), Windows дээр \textbf{WSL2 Ubuntu} дотор.
  \item Browser: Chrome, Safari, Firefox-ийн сүүлийн хувилбар.
  \item Windows дээр шууд ажиллахгүй (\code{pc.c} нь pthreads ба POSIX semaphore ашигладаг): \textbf{WSL2} эсвэл \textbf{virtual machine} доторх Ubuntu ашиглана.
\end{itemize}

\subsection{Windows: WSL2}
\begin{enumerate}
  \item PowerShell-ийг администратороор нээж \code{wsl --install -d Ubuntu}, компьютераа дахин асаана.
  \item Ubuntu терминалд compiler, Node.js суулгана:
\end{enumerate}
\begin{lstlisting}[style=shell,breaklines=true]
sudo apt update && sudo apt install -y build-essential git curl
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
\end{lstlisting}
\begin{enumerate}[start=3]
  \item "Суулгах, нээх" хэсгийн командуудыг Ubuntu дотор ажиллуулна. Windows-ийн browser дээр http://localhost:3000 шууд нээгдэнэ.
\end{enumerate}

\subsection{Windows: virtual machine}
VirtualBox, VMware эсвэл UTM дээр Ubuntu 22.04+ суулгаж, WSL2-ийн 2-р алхмын адил \code{build-essential}, Node.js суулгана.
\begin{itemize}
  \item VM доторх browser-оос: \code{npm run dev}, http://localhost:3000.
  \item Windows (host) browser-оос: VM-ийн IP хаягаар (\code{hostname -I}) хандана. Next.js dev server localhost-оос өөр хаягаас ирсэн хүсэлтийг хаадаг тул (хуудас нээгдэх ч товч ажиллахгүй) production горимоор ажиллуулна: \code{npm run build \&\& npm start}, дараа нь \code{http://<VM-ийн IP>:3000}.
  \item VM-ийн сүлжээ Bridged эсвэл Host-only байна; NAT бол 3000 портыг forward хийнэ.
\end{itemize}

\subsection{Хичээл ба заавар}\label{sec:learn}
Эхлээд 3 оршил слайд (тавтай морил, юу сурах, хэрхэн ашиглах) дуут уншлагатай гарна. Энэ хооронд хичээлийн бодит run ар талд бичигдэж, \textbf{Хичээл эхлүүлэх} товч бэлэн болмогц идэвхжинэ.
\begin{itemize}
  \item Эхний 5 алхам ойлголтыг заана: талхны дэлгүүрийн жишээ, яагаад буфер хэрэгтэй, гурван асуудал (дүүрэн, хоосон, race condition), компьютер дээрх буфер, \code{empty}/\code{full}/\code{mutex} багаж.
  \item Дараагийн 7 алхам бодит run-ийг алхам алхмаар тоглуулж, тухайн хэсгийг цэнхэр хүрээгээр тодруулна. Алхам хооронд бодит event-үүд нэг нэгээрээ тоглогдоно (тавих/авах бүрт 0.7 с), энэ үед \textbf{Алгасах} товчоор шууд дараагийн алхам руу очно.
  \item Буферийн дүрслэл алхмаас хамаарч өөрөө солигдоно: эхлээд Талх, дараа нь Хоолой, Массив.
  \item 5 алхамд асуулт байгаа, зөв хариулсны дараа үргэлжилнэ.
  \item Алхам бүрийг дуу хоолойгоор уншина (урьдчилан бичсэн \code{public/audio/learn/*.m4a}): тоглуулах/зогсоох товч, slider-аар гүйлгэж болно. Тавих/авах/хүлээх үед болон хариултад богино дуу гарна.
  \item \code{/learn}-ийг шууд хаягаар нээвэл browser эхний уншлагыг хааж магадгүй, тэр үед тоглуулах товчийг дарна.
\end{itemize}

\subsection{Ажиллуулах, зогсоох, reset}
\begin{itemize}
  \item \textbf{Start} (эсвэл Тохиргоо цонхны \textbf{Эхлүүлэх}): тохиргоогоор шинэ run эхлүүлнэ. Цонхны бэлэн туршилтын товч (Буфер дүүрэх / Буфер хоосрох / Race condition) тохиргоог бөглөөд шууд эхлүүлж, цонхыг хаана.
  \item \textbf{Stop}: ажиллаж буй C процессыг зогсооно, тэр хүртэлх event-үүд үлдэнэ.
  \item \textbf{Reset}: run-ийг зогсоож дэлгэцийг цэвэрлэнэ.
  \item Timeline дээр \textbf{дарж эсвэл чирж} аль ч агшин руу очно. \key{←} \key{→} нэг event, \key{Shift}+\key{←}/\key{→} 10 event, \key{Space} pause/play.
  \item \textbf{Доод bar} (дэлгэцийн доор үргэлж харагдана): видео тоглуулагч шиг slider (зүүн талд одоогийн хугацаа, баруун талд нийт хугацаа), \textbf{0.1× 0.25× 0.5× 1×} тоглуулах хурд (анхдагч 0.25×, 1× = бодит хугацаа), \textbf{Replay}, \textbf{Өмнөх}, \textbf{Тоглуулах / Түр зогсоох}, том хар \textbf{Дараагийн алхам} товч (нэг event урагшилна).
  \item \textbf{Event log} (өргөн дэлгэц дээр баруун талд, нарийн дэлгэц дээр timeline-ий доор): тоглогдсон event бүр доороос нэмэгдэнэ. Мөр дээр дарж тэр агшин руу очно. \textbf{JSONL} товчоор бүх event-ийг файлаар татна.
  \item C core бодит хугацаагаар ажилладаг, дэлгэц түүнийг сонгосон хурдаар араас нь тоглуулна. Core илгээсэн боловч хараахан тоглогдоогүй хэсэг timeline дээр бүдэг харагдана. Тавих/авах бүр дэлгэц дээр дор хаяж 0.6 с, хүлээх 0.4 с харагдана (0.25× үед, бусад хурдад харьцаагаар). 600-аас олон event-тэй run (жишээ нь Түвшин 3) зөвхөн хугацаагаар тоглогдож, хурд 0.1×-д түгжигдэнэ.
  \item Timeline-ий баруун дээд буланд \textbf{2 с / 5 с / Бүгд} цонх: анхдагч нь 2 с; 2 с, 5 с үед timeline playhead-ийг дагаж гүйнэ.
\end{itemize}

\subsection{Дүрслэлийн тэмдэг, өнгө, төлөв}
\textbf{Буферийн дүрслэл.} Тохиргоо цонхны "Буферийн дүрслэл" хэсгээс \textbf{Массив / Хоолой / Талх} гурвын аль нэгийг сонгоно (Хичээл дээр алхмаас хамаарч өөрөө солигдоно). Гурвуулаа ижил өгөгдлийг харуулна.
\begin{itemize}
  \item \textbf{Массив} (номын Figure 7.1 шиг): буфер = нүдний мөр (circular array). Цэнхэр нүдэнд item байна, саарал нүд хоосон, яг одоо хандсан нүд ногоон болж дээш өргөгдөнө (race бол улаан). \textbf{▲in} (ногоон) нь producer-ийн дараагийн тавих нүд, \textbf{▲out} (нил ягаан) нь consumer-ийн дараагийн авах нүд. Сүүлийн нүдний дараа [0] руу эргэж ирнэ.
  \item \textbf{Хоолой} (FIFO): item зүүн талаас орж, баруун талаас гарна. Хамгийн баруун талынх нь хамгийн эрт орсон тул эхэлж авагдана. Тасархай тойрог = сул зай (\code{empty}), цэнхэр = item (\code{full}).
  \item \textbf{Талх}: талхчин = producer, авагч = consumer, тавиур = буфер (модон хайрцагт нүд бүр нэг үүр, хоосон нүд тасархай хүрээтэй "сул", талх дээр item-ийн дугаар). Дээрх самбарууд: \textbf{Сул зай} = \code{empty}, \textbf{Хаалга} = \code{mutex} (онгорхой = чөлөөтэй, хаалттай бол дотор нь хэн байгаа), \textbf{Талх} = \code{full}.
\end{itemize}

\textbf{Thread карт ба сум.}
\begin{itemize}
  \item Thread бүр нэг карт: өнгөт avatar (producer цэнхэр, consumer ягаан), нэр, одоогийн төлөв icon-той (сар = унтаж, элсэн цаг = хүлээж). Саарал = унтаж байна, шар = semaphore хүлээж байна, цайвар цэнхэр/ягаан = тавьж/авч байна (гартаа item-ийн дугаартай), хар хүрээ + цоож = mutex эзэмшиж байна. 6-аас олон thread үед карт жижиг chip болно.
  \item Item тавихад producer-оос нүд рүү бөмбөлөг нисэж очно, авахад нүднээс consumer руу нисэнэ.
  \item Producer, буфер, consumer гурвын хооронд \textbf{тавина} ба \textbf{авна} сум байна. Тавих/авах агшинд тухайн сум цэнхэр/ягаан болж item-ийн дугаарыг харуулна, тал нь хүлээж байвал шар "хүлээж байна" болно.
  \item Буферийн доор том үсгээр одоогийн event, түүний доор "яагаад" гэсэн нэг мөр тайлбар (аль semaphore блоклосон, mutex-ийг хэн барьж байгаа) гарна. Доор нь \code{empty}, \code{full}, \code{mutex}, тавьсан, авсан тоо болон төгсгөлд invariant.
\end{itemize}

\subsection{Жишээ}

\textbf{Жишээ 3. Race condition} (P=8, C=8, буфер=5, ≤5 мс, 1 с, mutex унтраалттай). Critical section хамгаалалтгүй тул timeline дээр олон улаан тэмдэг гарна. 600-аас олон event-тэй тул дээр нь шар анхааруулга гарч, хурд 0.1×-д түгжигдэнэ. Race хэсгийн \textbf{Эхнийх}, \textbf{Дараагийнх} товчоор race-уудыг нэг нэгээр нь үзэхэд доор нь тайлбар гарна, жишээ нь "count = 2, 1 байх ёстой". Зарим run-д төгсгөлд \code{Invariant БУРУУ} гарна, энэ нь шинэчлэл алдагдсаныг (lost update) баталгаажуулна. Mutex-тэй ижил тохиргоонд race 0 гарна.

  \item Mutex-гүй үед log-ийн дараалал бодит дараалалтай яг таарахгүй (log бичих нь critical section-оос гадна), тиймээс race-ийг \code{count}-ийн зөрүүгээр илрүүлдэг.
  \item Нэг машин дээр зэрэг 4 хүртэл run.
\end{itemize}
